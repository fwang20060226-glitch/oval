# Revive the Tree — demo setup

Route: A (dead tree) → B (green seed) → A (leaves) → C (bloom seed) → A (flowers).

Open `index.html?fake` with VS Code Live Server to test using the labelled arrival buttons. This is a simulation, not a GPS or native AR test. Use **Restart game** for a new run; refreshing preserves progress.

Coordinates are now entered: A = Five Brothers Trees (39.999585, -83.012374); B = Tree in front of Hayes (40.000141, -83.011195); C = Statue (39.999364, -83.013888). **A was recorded at ±104 m and must be remeasured before the live demo**, ideally at ±10 m or better. B and C were recorded at ±5 m and ±4 m. Use `?scout` to record a replacement A coordinate, then copy it into `SPOTS`. Radius: 20 m. Every pair of spot centres must be farther apart than the sum of their radii.

Open the published page directly in Safari on iPhone/iPad. Wait for each model to load before continuing. Place the withered tree in AR before beginning; each seed remains available at its spot after collection. Return to Safari to give seeds. Web growth plays once and then swaps to a static tree for AR. Native Quick Look growth animation is not part of this version.

Upload the updated `index.html`, `vendor/` folder, `assets/` map folder, and all seven new `models/` files together. Include the new README, `game-preview.png` and preserved Training 2 documentation. A pushed HTML file without the model/library files will not work.

The live page must show **Revive the Tree** and **Freya & Wenxi**. The previous **Found on the Oval** page with a single growing tree is the old version.
