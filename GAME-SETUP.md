# Return to Bloom — demo setup

Route: A (dead tree) → B (green seed) → A (leaves) → C (pink seed) → A (flowers).

Open `index.html?fake` with VS Code Live Server to test using the labelled arrival buttons. This is a simulation, not a GPS or native AR test. Use **Restart game** for a new run; refreshing preserves progress.

Live coordinates are deliberately unconfigured in `SPOTS`. Use `?scout` on your HTTPS site to record A/B/C, then copy your measurements into `SPOTS`. Radius: 20 m. Every pair of spot centres must be farther apart than the sum of their radii.

Open the published page directly in Safari on iPhone/iPad. Wait for each model to load before continuing. Place the dormant tree in AR before beginning; each seed remains available at its spot after collection. Return to Safari to give seeds. Web growth plays once and then swaps to a static tree for AR. Native Quick Look growth animation is not part of this version.

Upload the updated `index.html`, `vendor/` folder, and all seven new `models/` files together. Include the new README, `game-preview.png` and preserved Training 2 documentation. A pushed HTML file without the model/library files will not work.

The live page must show **Return to Bloom** and **Freya & Wenxi**. The previous **Found on the Oval** page with a single growing tree is the old version.

See README for the concept, assets and deliverables. On-device AR placement, measured locations, the PDF map, personal portfolio entries and on-site demonstration video still require the team's work.
